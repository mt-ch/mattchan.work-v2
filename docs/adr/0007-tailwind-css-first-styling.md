# Styling: Tailwind 4 with Sass-generated fluid tokens

v2 styles with Tailwind 4 and design tokens as CSS variables exposed through `@theme`, and dark mode is a `data-theme` attribute variant. Sass is used only as in v1: `styles/functions.scss` (`fluid-space()`), `tokens.scss` and `utilities.scss`, imported by `app/globals.scss`, so responsive values are `clamp()` interpolations between the 480px and 2560px viewports rather than breakpoints. (Originally this ADR dropped Sass; reversed to keep v1's fluid-token setup.) The baseline needs no animation library: it uses CSS and React's `<ViewTransition>`, and a library such as `motion` is added only if #17 needs it, with its own ADR.
